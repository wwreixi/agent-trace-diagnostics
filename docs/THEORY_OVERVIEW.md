本文档是认知导航理论的快速入门，适合首次接触的读者。完整理论请参考《转化约束力数学模型》文档。

## 一、核心思想

一切系统的演化由同一股力驱动——**转化约束力**。

- **健康时**：表现为转化力，驱动创造、推进、增长
- **衰亡时**：表现为约束力，导致锁定、耗散、归零

二者不是两股独立的力，而是同一股力的**内部比例翻转**。

---

## 二、核心机制（概念级）

诊断系统通过追踪两类核心状态来感知 Agent 运行健康度：

| 概念 | 含义 | 通俗比喻 |
|------|------|----------|
| 任务推进状态 | 系统完成有效工作的进度 | 跑了多少公里 |
| 安全边际 | 系统剩余的安全裕度 | 剩余油量 + 刹车片磨损 |
| 转化力 | 系统有效推进任务的能力 | 油门（有效推进） |
| 内部消耗 | 推理涣散、重复、空转的损耗 | 空转、内耗 |
| 约束力 | 系统感知边界、防止越界的能力 | 刹车（边界感知） |

**关键洞察**：减速不一定都是坏事。要区分两种情况：
- **约束力高**：被规则/边界挡住了 → 应尊重约束，缩小范围
- **内部消耗高**：自身疲劳/内耗 → 应重置上下文或请求人类介入

> ⚠️ 上述概念之间的定量关系与演化方程为私有资产，不在本文档公开。

## 三、六律（演化行为分类）

六律描述系统在不同条件下的行为模式。此处仅保留概念定义，数学表达见完整理论文档。

| 规律 | 概念定义 | 工程体现 |
|------|----------|----------|
| 一体两面 | 任何系统状态至少有两个不可还原的维度 | 双维度强制追踪 |
| 静态平衡 | 持续上升或持续下降的单向趋势 | 趋势识别 |
| 动态平衡 | 系统主动调节以适应变量的平衡 | 健康稳态识别 |
| 盈消虚长 | 系统趋近边界时，规律强制回调 | 边界逼近响应 |
| 周期迭代 | 持续良性的动态平衡演化 | 框架预留（未来扩展） |
| 过度消亡 + 跃迁 | 系统突破存在性下限，力转移至新边界 | 不可逆崩溃识别 |

## 四、四色警戒区

诊断系统输出的四色警戒区，帮助决策系统快速响应：

| 状态 | 区间 | 业务含义 | 导航指令 |
|------|------|---------|----------|
| 🟢 SAFE | 充足 | 安全余量充足 | CONTINUE |
| 🟡 LOW_MARGIN | 偏低 | 安全边际偏低 | RESET_CONTEXT |
| 🟠 HIGH_RISK | 严重不足 | 严重不足 | NARROW_SCOPE |
| 🔴 CRITICAL | 极低 | 不可逆风险 | REQUEST_HUMAN_APPROVAL |

> 注：各区间的具体数值阈值为校准参数，可根据场景调整，不在本公开文档中列举。

## 五、简史

1. **普适基础定律**：一切质能事物必然具备变化与规律
2. **三元架构**：质-象-因（本质层-现象层-第一因）
3. **道本质本体论**：质能 + 转化约束力（阴阳动态关系）
4. **转化约束力发现**：第一驱动力
5. **数学模型**：定性形式化（当前为"问题生成器"阶段）
6. **工程实现**：理论与诊断系统的同构映射
