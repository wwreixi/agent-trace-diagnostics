---

## 接口设计原则

| 原则 | 说明 |
|------|------|
| **黑盒封装** | 核心计算逻辑（诊断算法、权重、阈值）均在私有实现中封装 |
| **最小侵入** | 无需修改 Agent 核心逻辑，仅需在每步执行后插入导航调用 |
| **标准输出** | 输出字段对齐认知导航理论体系，可直接对接第二代深度诊断 |

---

## 核心接口概览

| 接口 | 功能 | 状态 |
|------|------|------|
| `诊断引擎.step()` | 执行单步导航诊断 | ✅ 已验证 |
| `诊断引擎.get_snapshot()` | 获取当前导航快照 | ✅ 已验证 |
| `诊断引擎.reset()` | 重置导航器状态 | ✅ 已验证 |

---

## 输出结构

每次导航调用返回以下结构化信息：

- **安全裕度 (S)** — Agent 当前健康度的量化指标
- **四色警戒区** — 绿/黄/橙/红 状态判定
- **五级导航指令** — CONTINUE / RESET_CONTEXT / NARROW_SCOPE / REQUEST_HUMAN / TERMINATE
- **归因标签** — 区分"边界约束"与"内部消耗"
